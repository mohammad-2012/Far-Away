# 🌴 Far Away 🧳 - Travel Packing List

**Live Demo:** https://mohammad-2012.github.io/Far-Away

---

## Description

A simple yet practical travel packing list application built with React. Add items you need for your trip, check them off as packed, sort them, and clear the list when done. This project demonstrates core React concepts like components, state management, and event handling.

---

## Features

- ➕ Add new items to your packing list
- ✅ Mark items as packed/unpacked
- 🗑️ Delete individual items
- 🔄 Sort by input order, description, or packed status
- 🧹 Clear entire list
- 📊 Live statistics (total items, packed count, percentage)
